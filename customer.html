1. 사건자료 등록

가지고 있는 PDF를 그대로 올려도 됩니다.

PDF를 선택하면 이 브라우저에서 페이지 수와 분석 금액을 계산합니다. 현재 테스트 한도: PDF당 30MB, 전체 300페이지.

PDF 원문 추출 · 1차 검산

선택한 PDF에서 페이지별 텍스트를 읽고, 원문 위치를 확인합니다. 파일은 이 단계에서 서버로 전송하지 않습니다.

PDF를 선택하면 추출 가능한 텍스트와 페이지별 원문을 확인할 수 있습니다.

PDF 원본 페이지 보기 (시각 검산)

추출 텍스트와 실제 PDF 페이지를 직접 비교할 수 있습니다. 스캔 페이지도 화면으로 확인할 수 있지만 문자 인식은 별도입니다.

분석 준비 상태
PDF를 선택하면 분석 가능한 페이지와 확인이 필요한 페이지를 집계합니다.
원문 인용 검증
PDF의 문서명·페이지·인용 문장을 입력하면 실제 추출 원문에 있는지 확인합니다. 원문 존재 여부만 확인하며 사실관계의 진실성은 판정하지 않습니다.
PDF를 먼저 선택하세요.
분석 결과 출처 일괄 검산 · 시험
별도로 작성한 분석 결과 JSON을 불러오면 각 인용의 문서·페이지·원문 일치 여부를 한 번에 검사합니다. 아직 AI가 자동으로 분석 결과를 만드는 기능은 아닙니다.
 
PDF를 먼저 등록하세요.
사건자료 1차 색인
PDF를 선택하면 날짜·주요 표현·증거번호를 문서와 페이지별로 정리합니다.
   
검색 결과를 누르면 원문 페이지로 이동합니다. ‘이 문장 검토’를 누르면 검토 기록으로 가져옵니다.
원문 검산 기록
색인의 문장을 클릭해 원문을 확인한 뒤, 검토 상태와 메모를 남길 수 있습니다. 상태는 이용자가 직접 지정하며 자동 사실 판정이 아닙니다.
 
먼저 PDF 색인에서 검토할 문장을 선택하세요.
 
검토 기록은 현재 브라우저 화면에서만 유지됩니다. 새로고침하면 사라지므로 파일로 저장하세요.
