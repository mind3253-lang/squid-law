1. 사건자료 등록

가지고 있는 PDF를 그대로 올려도 됩니다.

PDF를 선택하면 브라우저에서 원문을 읽고 분석 결과를 자동으로 표시합니다. 현재 테스트 한도: PDF당 30MB, 전체 300페이지.

PDF 원문 추출 · 1차 검산

선택한 PDF에서 페이지별 텍스트를 읽고, 원문 위치를 확인합니다. 파일은 이 단계에서 서버로 전송하지 않습니다.

PDF를 선택하면 추출 가능한 텍스트와 페이지별 원문을 확인할 수 있습니다.

PDF 원본 페이지 보기 (시각 검산)

추출 텍스트와 실제 PDF 페이지를 직접 비교할 수 있습니다. 스캔 페이지도 화면으로 확인할 수 있지만 문자 인식은 별도입니다.

통합 사건 분석보고서
업로드한 PDF에서 확인되는 모든 항목을 한 보고서에 표시합니다. 아직 AI 의미 분석이 연결되지 않은 항목은 미분석으로 명시하며, 원문 후보를 법적 판단으로 표시하지 않습니다.
PDF를 먼저 등록하세요.
관리자 AI 실분석 시험 (비공개 접근)
서버에 시험 기능과 API 키가 설정되어야 작동합니다. AI 시험 한도는 PDF 5개·전체 30페이지·추출 텍스트 60,000자·전송 160KB입니다. 등록한 PDF의 추출 텍스트가 외부 AI에 전송됩니다. 실제 사건자료는 전송 권한을 확인하세요.
 
PDF를 등록한 뒤 실행하세요.
 
분석 준비 상태
PDF를 선택하면 분석 가능한 페이지와 확인이 필요한 페이지를 집계합니다.
서면 간 공통 증거번호 비교 · 시험
서로 다른 PDF에서 같은 증거번호가 언급된 문장을 나란히 보여줍니다. 모순이나 사실관계를 판단하는 AI 분석은 아닙니다. 원문 출처만 검산합니다.
  
PDF를 먼저 등록하세요.
원문 인용 검증
PDF의 문서명·페이지·인용 문장을 입력하면 실제 추출 원문에 있는지 확인합니다. 원문 존재 여부만 확인하며 사실관계의 진실성은 판정하지 않습니다.
PDF를 먼저 선택하세요.
비공개 AI 분석 파일럿 · 관리자용 준비
브라우저에서 추출한 PDF 페이지 텍스트를 비공개 AI 시험 입력 형식으로 저장합니다. 이 버튼은 외부 서버에 전송하지 않습니다. 개인정보·기밀정보가 포함된 자료는 외부 AI 전송 권한을 확인한 뒤 별도 관리자 환경에서만 시험하세요.
PDF를 먼저 등록하세요. 시험 한도: 전체 50페이지, 추출 텍스트 6만 자.
비공개 AI 시험 결과 검산
관리자 환경에서 생성한 AI 시험 결과 JSON을 가져와, 현재 PDF의 문서명·페이지·원문을 다시 대조합니다. 결과에 포함된 문장도 사실로 확정하지 않습니다.
 
먼저 원본 PDF를 등록하세요.
분석 결과 출처 일괄 검산 · 시험
별도로 작성한 분석 결과 JSON을 불러오면 각 인용의 문서·페이지·원문 일치 여부를 한 번에 검사합니다. 아직 AI가 자동으로 분석 결과를 만드는 기능은 아닙니다.
 
PDF를 먼저 등록하세요.
 
사건자료 1차 색인
PDF를 선택하면 날짜·주요 표현·증거번호를 문서와 페이지별로 정리합니다.
   
검색 결과를 누르면 원문 페이지로 이동합니다. ‘이 문장 검토’를 누르면 검토 기록으로 가져옵니다.
원문 검산 기록
색인의 문장을 클릭해 원문을 확인한 뒤, 검토 상태와 메모를 남길 수 있습니다. 상태는 이용자가 직접 지정하며 자동 사실 판정이 아닙니다.
 
먼저 PDF 색인에서 검토할 문장을 선택하세요.
 
검토 기록은 현재 브라우저 화면에서만 유지됩니다. 새로고침하면 사라지므로 파일로 저장하세요.
