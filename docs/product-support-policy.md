# SQUID LAW 운영·상품 정책 메모 (2026-10-08)

## 확정 방향
- 기본 분석 가격 기준: 50쪽당 29,000원(기존 기획). 기본 상품은 AI 분석 결과 화면 열람·검산·PDF 저장 중심.
- **수정가능본 다운로드**는 별도 과금. DOCX 및 HWPX 후보. 가격 미확정. “법원 제출용”이라는 명칭 사용 금지.
- 고객은 결과를 복사·저장할 수 있어야 함. 별도 과금 범위는 편집 가능한 완성 파일 생성·다운로드. 기본 복사 허용 범위와 상품 상세 정책은 최종 확정 필요.
- 별도 결제하더라도 문서 작성법·편집법·개별 사건 상담·수정 대행이 포함된다는 오해를 막아야 함.
- 고객 문의 전화가 폭증하지 않도록 셀프서비스 우선 설계. 온라인 문의/접수번호, 반복 질문 FAQ, 작업 상태 표시.
- 나이 많은 사용자도 별도 PDF 프로그램 설치 없이 **웹에서 결과 열람** 가능하게. '결과 보기', '파일 저장하기' 등 쉬운 명칭.
- 인쇄 기능은 사용 가능하더라도 고객 프린터·컴퓨터 설정을 개별 안내하는 운영 구조를 피할 것.
- 문서 생성 상태: 접수 완료 → 생성 중 → 다운로드 준비 완료 → 실패/재시도 안내. 새로고침 후 지속 여부, 예상 소요시간, 실패 처리 방식은 실제 백엔드 구현에 맞춰 사실대로 안내.
- 고객지원 범위는 결제 전 명확히 공지. 단, 법적 소비자 보호 의무와 정당한 장애·환불 지원까지 배제하는 문구는 쓰지 말 것.

## 구현 현황
- 현재 PDF 원문 복사, TXT·JSON 다운로드, 웹상 PDF 페이지 확인 및 로컬 색인만 구현.
- DOCX/HWPX 생성·다운로드, 결제, 사용자 인증, 서버 저장, 실제 AI 분석은 미구현.
- `api/analyze.js`는 보안상 잠금(503) 상태. 작동 중이라고 광고 금지.

## 개발 우선순위
1. 분석 결과의 정확한 원문 위치 추적 및 원문 인용 검증.
2. 개인정보 보호·인증·과금 통제 가능한 AI 분석 서버 연동.
3. 실제 분석 결과 검산.
4. 이후 유료 수정가능본·다운로드 및 자가진단형 고객지원 구현.

※ 내부 기획 메모. 홈페이지에 자동 노출하지 말 것.
