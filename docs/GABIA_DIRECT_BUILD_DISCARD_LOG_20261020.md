# 가비아 직접 완성 — 폐기 판단·재구축 작업지침 (2026-10-20)

## 사용자 최종 결정
- Vercel은 완성된 원본이나 정답이 아니다. 과거 E2E 통과·GitHub Actions 통과·Vercel READY는 실제 서비스 정상 작동의 증거가 아니며, 가비아로 기존 구조를 복제할 이유가 되지 않는다.
- **가비아 Ubuntu 서버를 유일한 목표 실행환경으로 삼아 웹·API·PostgreSQL·사설 파일 저장소·SKYNET 기억/대화·SQUIDLAW 분석 워커를 직접 통합 구현한다.**
- 의심스러운 임시 구조, 중복 구현, Vercel 전용 우회는 과감히 **실행경로에서 제외**한다. 기존 코드 보존/호환 때문에 정상적인 직접 서버 설계를 방해하지 않는다.
- 버린 구조는 무엇을 왜 버렸는지만 이 문서에 기록한다. 버린 코드를 다시 복구하거나 테스트를 되풀이하지 않는다. 단, 고객 원본 데이터·기존 분석 산출물·체크포인트·DB·계정·증거 기록은 코드와 구분하여 보존하고, 파괴적 변경 없이 이전 무결성을 확인한다.
- 사용자는 자잘한 수정/커밋/중간보고를 원하지 않는다. 관련 기능을 한 덩어리로 구현하고 서버에서 실제 검증 후 한 번에 보고한다. 커밋 수가 아니라 실사용 가능성이 완료 기준이다.

## 유지할 계약 (새 기능을 추가하지 말 것)
1. SKYNET은 경량 기억·검색·대화, SQUIDLAW는 GPT API 법률 분석. 공통 문서 무결성·체크포인트 모듈만 공유.
2. 고객 전체 사건 파일을 한 번에 접수, 내부에서는 분할 저장/페이지 처리/재개. 과금은 페이지 기준. 원문 SHA-256·쪽수·증거 출처 보존.
3. 웹사이트의 동시 접속은 정상 허용. **법률 분석 실행만 전체 고객 1건씩**, 나머지는 DB 대기열과 순번·예상 대기시간으로 처리.
4. 회원별/관리자별 접근 격리, 원본 불변 저장, 실패 시 체크포인트 재개, 중복 분석/청구 방지. 승인 없는 결제·데이터 삭제·운영 워커 실행 금지.

## 일괄 구현 순서
1. 현재 GitHub 전체 API/웹/DB/저장소/워커 호출 관계를 점검하여 **하나의 가비아 런타임 구성**을 결정한다. 임시 프리뷰 서버를 계속 이어붙이지 않는다.
2. 가비아 Node HTTP API와 웹 정적 제공, 기존 인증/세션, SKYNET 대화·기억, 고객 업로드·분석, PostgreSQL, 사설 객체 저장소를 같은 배포 단위로 연결한다.
3. 기존 원본 자료·회원·기억·분석 체크포인트를 목록화하여 해시 검증 후 안전하게 이전한다. 원본 데이터 삭제는 하지 않는다.
4. 가비아 Ubuntu에서 직접 기동·로그인·업로드·검색·분석·보고서·다운로드·동시접속/직렬분석·장애 재개·백업 복구를 **실제 요청**으로 검사한다. 불합격은 수정 후 다시 검증한다.
5. 가비아 실운영 준비가 확인되면 DNS/TLS 전환. 과거 Vercel을 되살려 완성품처럼 취급하지 않는다. 종료 및 토큰 폐기는 자료 검증과 명시 승인 후 수행한다.

## 확인된 실제 CI 결과 (2026-10-20)
- `cb22f0a`: 가비아 오프라인 게이트와 SKYNET 회귀 테스트 성공.
- 전체 Node 테스트: 722개 중 715 통과, 1 실패, 6 건너뜀. 실패는 `tests/continuous-worker-safety.test.mjs`가 과거 `WORKER_CONFIGURATION_MISSING`을 기대하지만 현재 프리플라이트는 `WORKER_OWNER_NOT_GABIA`, `WORKER_MISSING_CRON_SECRET`, `WORKER_MISSING_BLOB_READ_WRITE_TOKEN`, `WORKER_MISSING_DATABASE_URL` 등 구체 오류를 반환하기 때문. 해당 구형 기대값만 고치려고 별도 커밋하지 말고 워커 통합 때 정리한다.
- 실제 가비아 웹·API·워커 배포, 고객 데이터 이전, 가비아 실사용 E2E **미확인**. Vercel 종료 **미실행**.

## 다음 세션 실행 지침
**이 문서를 먼저 읽고, 이미 폐기 판단된 임시 코드의 재활용·보존을 목표로 삼지 말 것.** 새 파일 하나, 테스트 하나씩 커밋하지 말고 실제 가비아 통합 서비스 완성에 필요한 코드 묶음을 작성·검증한다. 가비아 SSH/배포 권한이 없으면 실서버 작업을 완료했다고 주장하지 말고, 가능한 통합 코드 작업과 실제 차단 지점을 구분하여 기록한다.
