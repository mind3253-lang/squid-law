# SQUIDLAW 파일 처리 · 페이지 결제 · 마이페이지 연동 명세

상태: **미적용 설계/모듈**. 현재 SKYNET 운영 파일 업로드 정책을 변경하지 않음. 연결 작업 시 본 문서를 기준으로 구현.

## 제품 규칙
- PDF/PNG/JPG(JPEG 포함)는 변환 없이 접수하고 기본 사용 페이지 차감.
- 그 밖의 지원 문서는 사용자에게 **변환 예상 페이지**를 보여주고 승인받은 뒤 PDF로 변환. 원본과 변환본 모두 사용자 파일 목록에 남김.
- 페이지는 SQUIDLAW 서비스 내 선불 이용 단위. 변환료는 현금 즉시 결제가 아니라 보유 페이지에서 차감.
- 암호 설정/암호화 문서는 **접수 거절**. 비밀번호 요청이나 암호 우회 없음.
- 엑셀 수식 **재계산 금지**, 매크로 실행 금지. 원본 저장 표시값/서식을 안전하게 재현하지 못하면 변환 실패로 처리. AI가 임의로 계산하지 않음.
- 변환 실패 시 변환분 예약 페이지 반환. 사용자에게 사유와 재시도 안내. 성공한 서비스 비용만 정산하는 정책의 세부 기준은 추후 확정.
- 서버 변환은 요청 응답에서 동기 실행하지 않고 별도 큐/워커에서 처리. 사용자별 한도, 동시 작업 제한, 시간초과, 재시도, 중복 정산 방지.
- 마이페이지에서 업로드 원본과 유료 변환 PDF 각각 조회·다운로드·삭제 요청 가능. 본인 인증 및 파일 접근 권한 검사 필수.
- 보관료는 원본+변환본 등 실제 저장 바이트 기준. 사용자가 삭제하면 이후 보관량 감소. 소송 증거의 보존 의무/법적 보류 파일은 물리 삭제를 제한하고 고지.
- 원본 변경 금지, SHA-256 및 변환 관계 기록, 변환 실패 로그와 정산 이력 보존.

## 작업 흐름
1. 업로드 → 확장자 + MIME/매직바이트 검사 → 악성 파일 검사 → 암호문서 검사.
2. 직접 접수 파일은 원본 저장 및 기본 사용량 정산.
3. 변환 대상은 예상 비용 안내 → 명시적 승인 → 페이지 원자적 예약.
4. 원본 불변 저장 → 작업 큐 → 격리된 변환 워커 → PDF 결과 검사.
5. 성공: PDF 저장, 다운로드 권한 등록, 예약 페이지 확정 차감.
6. 실패: 변환 페이지 예약 해제, 실패 원인 안내, 무결성 로그 기록.
7. 마이페이지: 파일 목록, 원본/변환본 다운로드, 사용 페이지, 사용 저장 용량, 삭제/보존 상태 표시.

## 구현 전에 확정할 값
- 형식별 변환 페이지 단가, PDF 기본 접수 단가, 파일/페이지/용량 제한.
- 저장 용량 과금 주기 및 삭제 이후 정산 시점.
- OCR 비용 및 스캔 PDF 처리 정책.
- 변환 엔진 선정과 HWP/HWPX/엑셀 출력 충실도 검증 기준.
- 백그라운드 작업 인프라, 악성 파일 검사, 접근 권한, 보존 기간.
- 지원되지 않는 파일에 대한 사용자 안내와 변환 가능한 형식 최종 목록.

## 연결 코드
`lib/squidlaw-file-policy.js`는 정책 분류, 페이지 견적, 필요한 작업 및 데이터 필드를 정의한 **미연결 모듈**이다. 실제 변환기·DB·과금·다운로드 API가 완성된 것처럼 취급하지 않는다.
