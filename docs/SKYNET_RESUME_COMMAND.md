# SKYNET — 중단·강제 리턴 후 이어하기 최상위 실행 명령

## 목표
SQUIDLAW 내부 관리자 AI **SKYNET**을 ChatGPT API에서 실제 제공되는 기능을 최대한 통합한 영구 대화·개발 동료로 완성한다. 축소판 챗봇을 만들지 않는다. 사용하지 않는 기능은 마지막에 제거한다. 현재 사용자가 확정한 방향은 `docs/SKYNET_CONTINUITY_AND_IMPLEMENTATION.md`에 있다.

## SQUIDLAW 고객 분석 확정 설계 (SKYNET과 혼동 금지)
다음 방에서도 `AGENTS.md` 제4절, `lib/customer-product-contract.mjs`,
`docs/SQUIDLAW_FULL_RESUME_COMMAND.md`를 읽는다. 고객 한 명의 사건
전체 자료를 한 번에 접수하고, **전체 고객 분석을 1건씩 직렬 처리**한다.
대기열 순번·예상 시간을 제공하고 페이지당 과금한다. 내부 PDF
처리 25/100MB 숫자를 올리는 것으로 문제 해결 보고 금지.
기존 원본은 보존, 대용량 작업은 분할/체크포인트/중단 재개.
SKYNET 관리자 PDF는 현재 바이트 범위 읽기·16페이지 구간 추출을 적용했지만 실자료 258페이지 E2E는 미검증이다. 고객용 분석·비PDF 경로까지 동일한 구조로 완성됐다고 주장하지 않는다.

## 세션 시작 시 무조건 실행
1. GitHub `mind3253-lang/squid-law`의 **최신 main**을 읽는다. `docs/SKYNET_CONTINUITY_AND_IMPLEMENTATION.md`, **이 파일**, `docs/SKYNET_TASK_MANIFEST.json`을 읽는다.
2. Vercel `squid-law` 최신 배포와 최근 커밋/테스트/로그를 확인한다. 권한 오류가 나면 구체적 차단 요인을 기록하고 다른 가능한 작업을 진행한다.
3. 매니페스트의 각 항목을 실제 현재 코드와 증거로 재평가한다. **verified + 최신 코드에서 유효한 검증 증거**가 있는 것만 건너뛴다. 단순히 커밋/코드/READY가 있다는 이유로 완료 처리하지 않는다.
4. 미완료 항목 중 의존성이 충족된 P0→P1→P2 순으로 실제 구현한다. 한 항목이 막혀도 독립 항목을 계속 진행한다.
5. 작업 전/중/후 매니페스트를 GitHub에 업데이트한다. `status`, `checkpoint`, `evidence`, `blockedReason`을 구체적으로 기록한다. 가능한 한 각 작업 완료와 상태 기록을 같은 변경에 포함한다.
6. 강제 종료, 도구 제한, 컨텍스트 소진, 권한 오류, 배포 지연이 생기면 **마지막 성공 체크포인트**를 기록한다. 다음 세션은 **미완료만 재개**한다. 완료된 작업을 처음부터 반복하지 않는다.
7. 실시간 작업 도중 사소한 커밋마다 사용자에게 보고하지 않는다. 작업을 가능한 만큼 지속하고 **완료 또는 실제 차단 시 한 번에** 결과를 보고한다. 10초마다 '커밋했다'는 메시지 금지.
8. 사용자의 기존 결정은 재질문하지 않는다. 새 결정이 꼭 필요할 때만 한 가지 구체적 질문을 한다.

## 상태 판정 규칙
- `todo`: 미시작 또는 검증 불명.
- `in_progress`: 진행 중. 반드시 현재 커밋/수정파일/다음 액션을 체크포인트에 기록.
- `implemented`: 코드가 있으나 검증 미완료. **건너뛰면 안 됨.**
- `blocked`: 구체적 원인 기록. 다른 항목은 계속.
- `failed`: 실패 원인/재시도 방법 기록.
- `verified`: 자동 테스트 + 필요한 실제 운영 검증 결과/커밋을 기록한 경우만. 이후 회귀 발생 시 재개.

## 불변 조건
- 자동저장은 기존 합의한 대화량에 도달하면 **매번 동의 없이 자동 실행**. API 관리자 인증은 외부 접근 차단이지 매번 승인받는 절차가 아님.
- 고객 자료, 기존 기억, 운영 데이터 **삭제·초기화·덮어쓰기 금지**. 파괴적 작업은 별도 승인.
- SKYNET은 별도 홈페이지가 아니라 squidlaw.co.kr 관리자 기능.
- OpenAI 모델/API 실제 사용 가능 여부는 실호출로 검증. API에서 제공하지 않는 ChatGPT 제품 기능은 솔직히 구분하고 동등한 기능을 통합 구현.
- 장시간 작업은 무한 HTTP timeout이 아니라 **영속 작업큐·체크포인트·재개**로 해결.
- 비밀키·환경변수 값·개인정보를 GitHub 로그/응답에 노출하지 않음.
- 이 명령서 자체는 ChatGPT 세션 밖에서 자동 실행되지 않는다. **다음 채팅방에서 이 파일을 읽도록 지시하거나, SKYNET 내부 지속 실행기가 구축된 후에만 자동 재개 가능하다.**

## 완료 판정
